# Digital Clock - Multiple Time Zones

A beautiful digital clock application that displays the current time in different time zones around the world.

## Features

🕐 **Digital & Analog Displays**: See time in both digital and analog clock formats
🌍 **Multiple Time Zones**: Add clocks for any timezone you want
💾 **Local Storage**: Your selected timezones are saved automatically
🎨 **Responsive Design**: Works on desktop, tablet, and mobile
🔄 **Real-time Updates**: Clocks update every second
🔄 **Reset Option**: Quickly reset to default timezones
✨ **Modern UI**: Beautiful gradient background and smooth animations

## How to Use

1. **Add a Time Zone**:
   - Select a timezone from the dropdown
   - Click "Add" to add it to your display

2. **Remove a Time Zone**:
   - Click the "×" button on any clock card to remove it

3. **Reset to Default**:
   - Click "Reset to Default" to go back to New York, London, and Tokyo

## Available Time Zones

- Americas: New York, Los Angeles, Chicago, Toronto, Mexico City, São Paulo
- Europe: London, Paris, Amsterdam, Berlin, Moscow, Istanbul
- Asia: Tokyo, Singapore, Hong Kong, Dubai, Bangkok, Mumbai
- Oceania: Sydney, Auckland

## Installation

1. Clone the repository
2. Open `index.html` in your web browser
3. Start adding time zones!
